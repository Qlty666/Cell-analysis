第二步：新电脑先补全对应板块

不需要一次装完所有依赖。打开“环境补全”页，点对应板块的“检查环境”；缺少组件时再点“一键补全”。

1. 进入环境补全

打开 /environment，页面会列出表达分析、虚拟筛选、分子动力学等全部功能板块。

2. 检查依赖

在要使用的板块点击“检查环境”，先确认 Python、R 包或对接工具是否可用。

3. 一键补全

检查未通过时点击“一键补全”。可在顶部填写自定义安装地址，或勾选同时安装 ML/DL 依赖。

4. 回到分析页

安装完成后从顶部导航进入对应分析页面开始使用。

说明：表达分析会检查 R；全自动集成流水线的“一键补全”覆盖表达分析、虚拟筛选与 Codex Skills，安装时间会更长。

第三步：标准运行流程

  1. 在“数据集搜索”页搜索感兴趣的数据集，或直接使用已知 GEO / ArrayExpress 编号。
  2. 进入“全自动流水线”或“表达分析”页，填写编号、输出路径和物种，必要时展开表单分组调整参数。
  3. 点击开始任务后，可在当前页实时查看日志；切到“任务进度”页可同时管理多个任务。
  4. 任务完成或中断时浏览器会弹窗提醒。完成的任务可回到对应页面查看结果表、图片和报告。
  5. 在“结果清单”页搜索文件名，查看每个结果的用途、路径与“结果图判读指南”。
设置保存

支持保存设置的页面会提供“保存设置 / 恢复设置 / 恢复默认”，参数存到当前浏览器标签页。

断点续跑

全自动流水线支持阶段断点续跑与 dry-run；暂停的任务可在原页继续。

已跑结果

全自动流水线页可直接填写工作目录加载已有结果，不要求重新运行。

按场景使用

表达数据分析

  • 在“表达分析”页填写数据集编号、输出路径与物种后开始。
  • 单细胞数据会执行 QC、双细胞、聚类注释、差异表达与富集；bulk / microarray 数据按样本级矩阵运行。
  • 非单细胞数据不会伪造细胞级结果；完成后可直接打开 result_report.html。

从表达谱推进到靶点

  • 在“全自动流水线”页填写工作目录、输出目录与数据集编号。
  • 流水线会依次执行关键基因筛选、证据富集、虚拟敲除、虚拟筛选、MD/ML 交接、网络毒理学/FAERS 与细胞反馈。
  • 首次运行可先使用 dry-run 查看每个阶段会运行还是已完成。

虚拟筛选与独立分子对接

  • “虚拟筛选”页适合从证据收集、受体/配体准备到对接分析的全流程；无输入数据时会明确提示缺失文件。
  • “分子对接”页使用独立工作目录，适合单独准备受体、配体库并运行 Vina。
  • 工作目录中填写相对路径时，文件需位于该工作目录下；对接结果会按亲和力排序并可下载 PDBQT。

敲除、网络毒理学与 FAERS

  • “虚拟敲除”页需要表达/计数输入；填写目标基因后可按需启用 scTenifoldKnk 或 CellOracle 风格分析。
  • “网络毒理学”页用化合物-靶点表与疾病基因表计算交集、PPI hub 与 Venn/C-T-P-D 网络。
  • “FAERS”页使用药物-事件计数表输出 ROR、PRR、BCPNN IC 与 EBGM 组合信号。

任务管理

“任务进度”页集中显示各流水线页启动的任务。刷新或切换页面不会清除正在运行的任务记录，返回原页面后会自动恢复日志轮询。

  • 排队中的任务会等待前面的任务完成，避免同一类流程并发冲突。
  • 运行中任务可暂停；暂停后从原页面点击“继续任务”恢复。
  • 完成或中断时会弹窗提示；中断提示会显示运行到的阶段与原因。
  • 不需要的任务历史可在任务进度页一键清空。

结果与报告

网页结果区优先展示“结果表 + 文件下载 + 图片画廊”。需要系统检查所有交付物时使用“结果清单”。

  • 结果清单支持按文件名、类型和用途筛选，点击行可展开说明，并联动打开对应指南章节。
  • 每个结果图的判读标准、输出路径和用途见结果清单页的“结果图说明与判断指南”。
  • 集成报告、run_manifest 等文件仍保留在对应工作目录的 outputs 中，可作为复现记录。
