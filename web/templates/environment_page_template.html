对应命令行

网页端调用项目统一的 launchers\install_environment.py。命令行也可以直接执行：

python launchers\install_environment.py list
python launchers\install_environment.py check expression
python launchers\install_environment.py install docking --with-ml
python launchers\install_environment.py install full

各板块的 launchers\install_*.bat 与 check_*.bat 仍可直接双击使用；详细说明见项目 README 与 docs/software_guide.md。
