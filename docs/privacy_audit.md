检查范围：当前 `HEAD` 的受版本控制文件，以及所有本地分支可到达的 Git 历史
文件路径。检查过程没有读取或输出任何密钥值。

## 结论

当前受版本控制的代码中未发现硬编码的 API key、密码、私钥、证书、数据库、
真实 `.env`、日志或大型结果文件。`main` 的提交作者邮箱为 GitHub noreply
地址，没有发现其他个人邮箱。

## 已处理的问题

- 网页“实验方案一”表单曾包含一个本机绝对路径占位示例，现改为相对路径
  `../experiment_plan_one_results`。
- 测试用例中的内部项目绝对路径已替换为通用示例路径，避免公开仓库暴露
  本机目录结构。
- 私密专用流水线默认不在网页显示，相关表单、教程、环境卡、结果说明和版本
  条目只有在显式设置 `LIVER_ENABLE_PRIVATE_PLAN_ONE=1` 时才渲染；启用时网页
  只允许绑定 loopback，不能监听公开主机。
- 新增 `.env.example`，只包含变量名和空值；真实 `.env`、`.env.*`、私钥、
  证书、SQLite、日志和历史记录继续由 `.gitignore` 排除。

## 仍属于隐私风险的行为

- 联网运行会把疾病名称、基因符号、UniProt/Ensembl 标识、化合物 CID、
  SMILES、数据集编号等研究标识发送给公开数据库和 API。
- 如果设置了 `NCBI_EMAIL`，该地址会作为请求标识发送给 NCBI。
- 如果设置了 `LIVER_CONTACT_EMAIL`，该地址会写入外部 HTTP 请求的
  User-Agent。
- 默认不向第三方上传原始表达矩阵、单细胞矩阵或本地文件内容；但对接、
  单细胞、ML 和 MD 输出仍可能包含本机路径、样本编号、候选靶点和未公开
  研究结论。
- 网页服务默认只监听 `127.0.0.1`。如果改为非本机地址，会启用运行时访问
  令牌并输出到控制台；控制台日志不应公开分享。
- `web/task_history.json`、`web/validation_run.log` 等本地文件已被忽略，
  但其中可能记录工作目录、任务名称和运行状态，不应打包或上传。

## 使用建议

- 未公开课题优先使用 `--evidence-hub-offline`、本地证据文件或本地预测文件。
- 不要提交 `.env`、研究数据、分析输出、日志、数据库或含绝对路径的报告。
- 如需公开分享报告，先运行路径和样本标识脱敏检查。
- 任何凭据一旦出现在截图、日志或 Git 历史中，应立即在服务端轮换，而不只是
  删除当前文件。
