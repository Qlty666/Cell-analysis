# 实验方案一与参考文献对照评估

评估对象是 `实验方案一 .docx`、所给 8 篇参考文献，以及
`src/experiment_plan_one` 的完整流程。文献中的实验设计、数据集和结论只能作为方法依据；它们不是本项目的输入结果，也不能替代本项目的真实运行。

## 结论

脚本已经覆盖方案的主要计算链条：6PPD-Q 化合物表征、靶点来源、NAFLD 疾病靶点、富集和 PPI、GSE89632 训练、外部队列、机器学习/SHAP、小鼠和人类单细胞、虚拟扰动、对接、MD 准备及结果审计。它能生成论文所需的多数图表和机器可读中间结果。

它不能在没有外部数据授权、R/Scanpy/RDKit、Vina、GROMACS 和 gmx_MMPBSA 的情况下自动产生完整论文结果。脚本会把缺少数据或工具标成失败、准备态或近似方法，不能把这些状态当成正式实验结果。

## 必须保持的终点边界

方案中的队列不是同一个临床终点：GSE89632 是健康、单纯性脂肪变和 NASH；GSE49541 是轻度与晚期纤维化；GSE164441 是 NAFLD 相关 HCC 与癌旁组织。GSE135251 才是具有健康对照和 NAFLD 肝活检、适合作为 NAFLD 外部验证的队列。GSE164441 的 10 对 HCC/癌旁设计也被公开研究明确描述为 NAFLD-HCC 终点，而不是 NAFLD 诊断终点。[GSE135251 数据集概述](https://usebiotransfer.org/tools/geo-finder/GSE135251/)，[GSE164441 队列说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC10210691/)

因此配置已将 GSE135251 标为 `primary_external_validation_nafld`。GSE49541 和 GSE164441 仍然保留，但只能报告为纤维化进展和 HCC 相关验证；不能用方案中的 NAFLD AUC 目标解释它们。

## 与参考文献的对应

- 2025 年人群研究提示血清 6PPD-Q 与胆红素、甘油三酯和肝损伤存在关联；这是观察性关联，不能被本流程写成因果效应。可作为研究背景和讨论依据，不能替代动物或细胞暴露实验。
- 2026 年 6PPD-Q/NASH 研究采用网络毒理学、机器学习、单细胞、虚拟敲除和对接，并把 ESD 作为候选机制；本脚本采用相同的模块化思路，但核心基因必须由本项目数据重新选择，不能直接移植 ESD 结论。
- BCAT1、CEBPB、BaP/TGFBR1 和丁香酚研究支持“靶点交集 → 机器学习/SHAP → 单细胞定位 → 虚拟扰动 → 结构模拟”的可解释链条，同时也提醒这些计算结果是可检验假设。脚本对 CellChat、WGCNA 和 scTenifoldKnk 的近似实现均已在报告中显式标记，不能冒充原始软件结果。
- 所给文献的可迁移方法边界分别是：人群 6PPD-Q 研究提供暴露—肝损伤关联背景；6PPD-Q/NASH 研究提供 ESD 机制假设和动物验证对照；BCAT1 研究提供 SHAP/WGCNA/虚拟敲除/结构模拟的整合范式；BaP/哮喘研究提供 Mendelian randomization 与单细胞定位的补充思路；CEBPB/DEGDB 研究展示单细胞、虚拟敲除和体外验证如何闭环；BaP/房颤研究强调“单细胞定位不等于暴露后的直接重塑”；依诺肝素/骨质疏松研究说明临床暴露—结局、非线性剂量关系与网络毒理学应分开建模；丁香酚/肝损伤研究展示对接、MD、SPR 和多组学验证之间的证据等级差异。上述论文不能直接替本项目证明 6PPD-Q 的 NAFLD 因果机制。
- 方案要求避开已被 6PPD-Q/MAFLD 文献反复讨论的 TNF、IL1B、IL6、TP53、MAPK14 和 PTGS2。配置新增 `novelty_exclusions`，这些基因不再进入核心基因的单细胞和对接主线；它们仍可在交集和背景结果中出现，便于透明报告。

## 统计和复现要求

1. GSE89632 的模型选择使用嵌套交叉验证；特征筛选必须在训练折内完成。外部验证只允许一次性评估，不能根据外部 AUC 调参。
2. 训练、纤维化、HCC 和 NAFLD 队列分别保存终点、样本数、标签映射和 AUC 置信区间。小样本外部队列的 AUC 只能作为不确定性较大的验证证据。
3. 细胞组成和差异表达应以生物样本为重复单位；单细胞层面 Wilcoxon 结果只能作为探索性结果。细胞类型 pseudobulk 模块和 `inference_level` 字段用于区分两者。
4. 对接的盲对接盒、晶体配体盒和 AlphaFold 结构必须记录来源、分辨率/置信度、盒中心、盒大小和结构哈希。MD 只有在轨迹、日志、时长和分析文件均通过检查后才能进入论文结果。
5. 每次运行的 `10_reports/analysis_manifest.json` 记录代码哈希、Git 提交、软件版本、配置、随机种子、数据集角色和结果文件 SHA-256；阶段签名包含本模块源代码，代码修改不会误用旧缓存。
