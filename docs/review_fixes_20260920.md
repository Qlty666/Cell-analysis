- 高级 ML 从完整表达特征开始，在训练折内筛选，使用嵌套交叉验证估计模型选择流程的表现。支持按患者或供体分组，保存外层预测和特征记录。

- 虚拟敲除证据要求完成状态、配置指纹、非空产物和输入/输出哈希匹配，空摘要不能提高报告证据等级。
- 共享 HTTP 下载器验证长度、Content-Range 和续传资源标识，完整文件原子替换。
- CI 移除依赖安装失败后的无版本回退，加入强制 R 语法检查和真实 DESeq2 冒烟测试；Windows 启动器支持显式 LIVER_PYTHON。

## 使用与迁移

1. 无指纹的旧缓存会失效，请预留重新计算时间。历史对接 CSV 和强制 MD 运行目录保留在对应 history 目录。
2. ML 元数据可配置 group_column，或使用 patient、patient_id、donor、donor_id 自动识别；每类需要足够的独立组支持交叉验证。
3. 细胞类型 pseudobulk 的协变量通过 LIVER_DE_COVARIATES 设置，以逗号分隔；混杂、重复不足和秩亏不会被当成有效统计推断。
4. LIVER_PYTHON 应指向已有且安装所需依赖的 Python 可执行文件。
